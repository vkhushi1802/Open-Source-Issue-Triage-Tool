# Open-Source-Issue-Triage-Tool
The Open Source Issue Triage and Developer Assignment Tool is a C++ application that organizes software issues, prioritizes tasks, assigns developers based on skills and capacity, manages dependencies, and compares algorithmic strategies for efficient project planning.



Activity Selection: Which tasks can one developer complete without scheduling conflicts?

Interval Partitioning: How many developers are needed to execute all given activities without overlap?

Knapsack: Which combination of issues should we select within a developer's limited working hours?



I want you to remember this distinction:
- Dependency graph: What must happen before what?
- Weighted graph: What is the minimum-cost route?
- Assignment graph: Which developer should be connected to which issue?
